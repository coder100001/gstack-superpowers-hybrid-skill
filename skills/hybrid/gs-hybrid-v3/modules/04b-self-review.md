# 04b — Execution Layer: SELF_REVIEW → QA

## SELF_REVIEW 状态

**触发条件**: L3 任务 (L1/L2 可选)

### 目标

在 Execution Layer 内进行自审，确保代码质量、测试策略完善、边界条件覆盖充分，并符合 Governance 层的安全规则。

### 1. 测试策略自审

#### 1.1 单元测试

- [ ] **覆盖率要求**
  - 核心逻辑覆盖率 >= 80%
  - 关键路径覆盖率 >= 90%
  - 边界条件覆盖率 >= 100%

- [ ] **测试质量**
  - 测试是否独立
  - 测试是否可重复
  - 测试是否快速

- [ ] **测试场景**
  - 正常场景
  - 异常场景
  - 边界场景

#### 1.2 集成测试

- [ ] **接口测试**
  - 输入验证
  - 输出验证
  - 错误处理

- [ ] **数据流测试**
  - 数据转换
  - 数据持久化
  - 数据一致性

#### 1.3 端到端测试

- [ ] **用户场景**
  - 主流程
  - 备选流程
  - 异常流程

### 边界条件识别

#### 输入边界

### 2. 安全规则自审（Governance 层适配）

依据 Governance 层的安全规则进行检查，而非调用 `/cso`。

#### 2.1 输入验证

- [ ] **SQL 注入**
  - 所有用户输入是否经过参数化
  - 动态查询是否安全
  - ORM 使用是否正确

- [ ] **XSS 防护**
  - 输出是否转义
  - 富文本处理是否安全
  - CSP 是否配置

- [ ] **命令注入**
  - 是否执行用户输入的命令
  - 系统调用是否安全
  - 路径遍历防护

#### 2.2 认证与授权

- [ ] **身份认证**
  - 密码策略是否合规
  - 会话管理是否安全
  - MFA 是否支持

- [ ] **权限控制**
  - 最小权限原则
  - 水平越权检查
  - 垂直越权检查

- [ ] **Token 安全**
  - JWT 配置是否正确
  - Token 过期策略
  - Token 刷新机制

#### 2.3 敏感信息

- [ ] **密钥管理**
  - 密钥是否硬编码
  - 密钥轮换机制
  - 密钥存储安全

- [ ] **日志脱敏**
  - 敏感信息是否脱敏
  - 日志访问控制
  - 日志保留策略

- [ ] **配置安全**
  - 配置文件权限
  - 环境变量使用
  - 敏感配置加密

#### 2.4 通信安全

- [ ] **传输加密**
  - TLS 配置
  - 证书管理
  - 加密算法选择

- [ ] **API 安全**
  - 速率限制
  - 请求大小限制
  - CORS 配置

## QA 验证状态

**触发条件**: SELF_REVIEW 通过后

### QA 验证目标

基于自审结果进行质量验证，确保交付物符合质量标准。

### QA 验证清单

- [ ] 验证自审报告完整性

## 安全异常处理

### 发现安全问题的处理流程

```
发现问题 → 评估风险 → 紧急修复 → 重新自审 → QA 验证
```

### 风险分级

| 级别 | 定义 | 响应时间 | 处理方式 |
|------|------|---------|---------|
| **Critical** | 可导致系统被完全攻破 | 立即 | 停止所有工作，立即修复 |
| **High** | 可导致严重数据泄露 | 24小时 | 优先修复 |
| **Medium** | 可导致有限影响 | 1周内 | 计划修复 |
| **Low** | 影响较小 | 下次迭代 | 记录跟踪 |

### 修复验证

修复后必须：
1. 重新运行安全扫描
2. 验证修复有效性
3. 确认无回归问题
4. 更新自审报告

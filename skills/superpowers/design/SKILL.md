# Design

Generate or refine a design doc for the current task:
- State problem and constraints
- Compare at least 2 options with tradeoffs
- Pick one option with clear rationale
- List risks and rollback plan
- Define API/data-contract impact if any

Output should be concise and implementation-ready.

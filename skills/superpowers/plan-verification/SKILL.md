# Plan Verification

Verify the execution plan before implementation:
- Scope is explicit and unchanged from requirement lock
- Task breakdown is actionable and ordered
- Risks and mitigations are stated
- Acceptance criteria are testable
- User confirmation is explicit

If any item is missing, block and return a concrete fix list.

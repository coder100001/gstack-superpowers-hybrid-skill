# ADR-005: 渐进式加载策略

- **状态**: ✅ 活跃
- **日期**: 2026-01-19
- **影响范围**: context-layer

## 背景

一次性全量加载所有技能和上下文模块导致初始 token 消耗过高（> 50KB），会话启动慢，且大量未使用的模块浪费上下文窗口，影响 Agent 响应质量。

## 决策

采用**按需渐进加载**策略：

- 初始加载仅包含核心路由和复杂度评估模块（< 20KB token）
- 运行时根据复杂度评估结果动态加载所需模块
- 单模块大小严格控制在 < 10KB
- 峰值上下文控制在 < 30KB token

## 后果

- **正面**: 初始加载时间显著缩短
- **正面**: 上下文窗口高效利用，减少浪费
- **正面**: 支持更大规模技能库的扩展
- **负面**: 引入运行时动态加载的复杂性
- **负面**: 模块间可能产生隐式依赖延迟

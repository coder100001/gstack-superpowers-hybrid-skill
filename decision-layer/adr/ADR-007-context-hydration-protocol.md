# ADR-007: 上下文水合协议

- **状态**: ✅ 活跃
- **日期**: 2026-01-19
- **影响范围**: context-layer, bridges

## 背景

执行阶段常因上下文缺失（缺少约束条件、架构规则或领域边界信息）导致决策偏差或输出不符合项目规范。Agent 在执行复杂任务时容易遗忘或忽略早期的上下文约束。

## 决策

实现**强制预执行水合机制（Context Hydration Protocol）**：

- 执行前必须先加载对应上下文模块
- 水合内容包含：约束契约 + 架构规范 + 领域边界
- 水合通过 Bridges 层传递
- 关键水合点设置检查哨，确保上下文完整

## 后果

- **正面**: 执行质量提升，减少因上下文缺失导致的返工
- **正面**: 项目规范得到更一致的遵守
- **负面**: 引入额外的水合加载步骤（< 2s 开销）
- **负面**: 水合内容需要与执行阶段精确匹配

# ADR-003: Superpowers + GStack 混合集成

- **状态**: ✅ 活跃
- **日期**: 2025-11-22
- **影响范围**: 技能体系

## 背景

纯 Superpowers 路线具备完善的 AI 工程方法论（需求分析、规划、TDD、调试），但缺少浏览器自动化和 QA 能力。纯 GStack 路线拥有强大的浏览器自动化和测试工具链，但缺少 AI 工程技能的方法论支撑。两条路线各有所长却互有盲区。

## 决策

采用**混合集成路线**：将 Superpowers 和 GStack 两套技能系统以互补方式整合：

- Superpowers 提供 AI 工程方法论（brainstorming, writing-plans, TDD, debugging）
- GStack 提供浏览器自动化和 QA 能力
- 通过 Hybrid 编排层统一调度
- 保留各自独立的技能目录结构

## 后果

- **正面**: 覆盖从需求到交付的完整生命周期
- **正面**: 复用两套成熟系统的已有成果
- **负面**: 两套系统的命名和风格差异需要调和
- **负面**: 需要额外的编排层来统一调度

# ADR-006: 灵活工作流路由 (L1/L2/L3)

- **状态**: ✅ 活跃
- **日期**: 2026-01-19
- **影响范围**: 全流程

## 背景

固定流程强制执行导致简单任务（如修改变量名）也需要走完整的需求分析、规划、评审、实现、验证全流程，效率低下。用户反馈"小改动也要等半天"。

## 决策

采用**基于复杂度的灵活路由**，不强制执行固定流程：

- **L1**: 单文件修改，无架构影响 → 直接执行，事后记录
- **L2**: 多文件修改，局部架构影响 → 设计评审 → 确认 → 执行
- **L3**: 跨模块修改，全局架构影响 → 完整流程 → 多轮评审 → 确认 → 执行
- 复杂度由 Step 0 评估阶段自动判定并路由

## 后果

- **正面**: 简单任务大幅提速，减少不必要的流程开销
- **正面**: 复杂任务仍保留充分的评审和验证环节
- **负面**: 复杂度判定标准需要持续校准
- **负面**: L1 变更可能因误判跳过必要步骤

# ADR-001: 初始三层架构设计

- **状态**: ✅ 活跃
- **日期**: 2025-11-22
- **影响范围**: 全项目

## 背景

混合技能系统需要统一的架构框架来组织日益增长的技能模块、约束条件和执行流程。之前缺乏明确的架构分层，导致模块职责模糊、依赖关系混乱。

## 决策

采用 **三层架构（Decision/Context/Execution）+ Bridges + Governance** 作为核心架构模式：

- **Decision Layer**: 架构决策记录、变更审议、架构冻结控制
- **Context Layer**: 约束契约、规范定义、运行时上下文
- **Execution Layer**: 计划执行、代码实现、交付验证
- **Bridges**: 层间通信和数据流转
- **Governance**: 合规检查和执行保障

## 后果

- **正面**: 模块职责清晰，依赖方向明确，可维护性提升
- **正面**: 变更影响可评估（L1/L2/L3 分级）
- **负面**: 小变更需经过层次路由，增加轻微开销
- **负面**: 新成员需要理解三层概念模型

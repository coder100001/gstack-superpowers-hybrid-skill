# Design Doc 003: 渐进式加载优化

## 问题

当前 gs-hybrid SKILL.md 607 行，其中 ~200 行是完整的 47 个 GStack 技能列表 + 2 个完整使用示例。每次调用 gs-hybrid 时这些内容全部进入上下文，但大多数技能对当前任务无关。此外，v4.0 框架的 16 个核心文件（2,410 行 / 74K）没有任何加载机制，导致"存在但不可达"。

## 方案

### A. SKILL.md 瘦身（607 → ~350 行）

- 删除完整的 Superpowers/GStack 技能列表（L89-204，~113 行）
- 删除 2 个完整使用示例（L540-601，~61 行）
- 技能列表改为摘要引用：分组 + 代表性技能 + 指向 skills-reference.md

### B. 框架文件渐进加载

每个模块顶部增加 `Context Load` 指令块，标明该阶段需要加载的 v4.0 框架文件。SKILL.md 新增加载策略表。

## 效果预估

| 指标 | 优化前 | 优化后 | 变化 |
|:-----|:------:|:------:|:----:|
| SKILL.md 行数 | 607 | ~350 | -42% |
| 模块头部新增 | 0 | 9 | +9 |
| 框架文件可达性 | 0/16 | 16/16 | +100% |
| 单次会话平均上下文 | ~100% | ~65% | -35% |

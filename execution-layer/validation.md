# Validation Rules

> **层**: Execution Layer · **职责**: 交付验收
> **前置条件**: 代码审查通过（见 review.md）
> **禁止**: 跳过验收、降低标准、带病上线

---

## 1. 用户验收标准（UAT）

### 1.1 功能验收
- [ ] 所有需求功能正常工作
- [ ] 用户流程完整可用
- [ ] 边界情况处理正确
- [ ] 错误提示友好清晰
- [ ] 符合用户体验要求

### 1.2 验收流程
```
准备阶段 → 执行阶段 → 签字确认
   ↓           ↓           ↓
环境准备    用例执行    验收报告
数据准备    问题记录    交付确认
```

---

## 2. 性能验证

### 2.1 性能指标
| 指标 | 阈值 | 测量方法 |
|:-----|:-----|:---------|
| 页面加载 | < 2s | LCP |
| API 响应 | < 500ms | P95 |
| 并发用户 | ≥ 100 | 压测 |
| 资源使用 | CPU < 70%, 内存 < 80% | 监控 |

### 2.2 性能测试
- 基准测试：建立性能基线
- 负载测试：验证正常负载下表现
- 压力测试：探索系统极限
- 稳定性测试：长时间运行验证

---

## 3. 安全验证

### 3.1 安全检查清单
- [ ] 输入验证完整
- [ ] 认证授权正确
- [ ] 敏感数据加密
- [ ] 无注入漏洞
- [ ] 无 XSS/CSRF 风险
- [ ] 依赖无已知漏洞
- [ ] 错误信息不泄露敏感数据

### 3.2 安全测试
- 静态代码安全扫描（SAST）
- 动态应用安全测试（DAST）
- 依赖漏洞扫描
- 渗透测试（关键系统）

---

## 4. 部署验证

### 4.1 部署前检查
- [ ] 所有测试通过
- [ ] 代码审查完成
- [ ] 发布文档齐全
- [ ] 回滚方案准备
- [ ] 监控告警配置

### 4.2 部署流程
```
1. 预发布环境验证
   ├─ 功能回归测试
   ├─ 性能验证
   └─ 安全扫描

2. 灰度发布
   ├─ 10% 流量
   ├─ 监控关键指标
   └─ 逐步扩大范围

3. 全量发布
   ├─ 持续监控
   ├─ 日志跟踪
   └─ 异常告警
```

### 4.3 部署后验证
- [ ] 系统正常启动
- [ ] 关键功能正常
- [ ] 性能指标正常
- [ ] 无错误日志
- [ ] 监控数据正常

---

## 5. 验收交付

### 5.1 交付标准
- ✅ 所有验收测试通过
- ✅ 性能指标达标
- ✅ 安全检查通过
- ✅ 部署验证完成
- ✅ 文档齐全

### 5.2 交付物
- 验收测试报告
- 性能测试报告
- 安全扫描报告
- 部署操作手册
- 运维监控指南

---

## 6. 异常处理

### 6.1 问题分级
| 级别 | 定义 | 响应时间 |
|:-----|:-----|:---------|
| P0 | 系统不可用 | 立即处理 |
| P1 | 核心功能异常 | 1h 内 |
| P2 | 功能受损 | 4h 内 |
| P3 | 体验问题 | 24h 内 |

### 6.2 回滚触发条件
- P0/P1 问题无法快速修复
- 性能严重下降
- 安全问题暴露
- 数据异常

# GStack & Superpowers Hybrid Skills

这个项目是一个完整的混合技能包，结合了 **Superpowers** 的开发方法论和 **GStack** 的强大功能，为您的 AI 编码助手提供超能力。

## 项目概述

本项目将两套开源技能包整合在一起：
- **Superpowers**：完整的软件开发方法论，由一系列可组合的技能和初始指令组成
- **GStack**：增强的开发工具和技能，包括浏览器自动化、设计评审、QA 测试等

## 快速开始

```bash
# 1. 添加脚本执行权限
chmod +x scripts/*.sh

# 2. 检查上游更新
./scripts/sync-upstream.sh --check

# 3. 同步上游技能
./scripts/sync-upstream.sh

# 4. 验证安装
ls skills/*/SKILL.md | wc -l  # 应该显示 18+
```

## 安装

### 方法 1：在 Trae 中使用（推荐）

```bash

cp -r . ~/.trae-cn/superpowers
```

然后重启 Trae，技能将自动加载。

### 方法 2：在 Claude Code 中使用


```bash

cd gstack--superpowers--hybrid-skill

# 2. 添加权限

```

详细安装说明请查看 [INSTALL.md](INSTALL.md)。

## 包含的技能

### Superpowers 核心技能库

**测试与验证**
- **test-driven-development** - RED-GREEN-REFACTOR 循环，包含测试反模式参考

**调试与诊断**
- **systematic-debugging** - 4 阶段根本原因分析流程
- **subagent-driven-development** - 快速迭代，带两阶段审查（规范符合性，然后代码质量）

**协作与规划**
- **brainstorming** - 苏格拉底式设计细化
- **writing-plans** - 详细的实施计划
- **executing-plans** - 带检查点的批量执行
- **dispatching-parallel-agents** - 并发子代理工作流
- **requesting-code-review** - 预审查清单
- **receiving-code-review** - 回应反馈
- **using-git-worktrees** - 并行开发分支
- **finishing-a-development-branch** - 合并/PR 决策工作流

**元技能**
- **writing-skills** - 遵循最佳实践创建新技能
- **using-superpowers** - 技能系统介绍

### GStack 扩展技能库

**增强开发工具**
- **gs-hybrid-v3** - GStack 混合技能 v3（主增强包）
- **gstack-browse** - 浏览器自动化和网页交互
- **design** - 设计工具和设计评审流程
- **design-consultation** - 设计咨询服务
- **design-html** - HTML 设计生成
- **design-review** - 设计审查
- **design-shotgun** - 多方案设计
- **review** - 多维度代码审查专家
- **qa** - 质量保证和测试工具

### GStack 工具脚本

`gstack-skills/bin/` 目录包含各种实用工具脚本：
- 开发环境设置与管理

## 工作流程

1. **头脑风暴** - 在编写代码前激活。通过问题细化粗略想法，探索替代方案，分块展示设计以供验证。
2. **使用 Git Worktrees** - 设计批准后激活。在新分支上创建隔离工作区，运行项目设置，验证干净的测试基线。
3. **编写计划** - 批准设计后激活。将工作分解为小块任务（每个 2-5 分钟）。每个任务都有精确的文件路径、完整代码和验证步骤。
4. **子代理驱动开发或执行计划** - 有计划后激活。为每个任务分配新子代理并进行两阶段审查，或分批执行并带有人工检查点。
5. **测试驱动开发** - 实施期间激活。强制执行 RED-GREEN-REFACTOR：编写失败测试、观察失败、编写最少代码、观察通过、提交。删除在测试前编写的代码。
6. **请求代码审查** - 任务之间激活。对照计划审查，按严重性报告问题。关键问题阻止进度。
7. **完成开发分支** - 任务完成时激活。验证测试，提供选项（合并/PR/保留/丢弃），清理工作树。

## 维护与更新

### 同步上游更新

当 superpowers 或 gstack 更新时，使用同步脚本获取最新内容：

```bash
# 同步所有上游更新
./scripts/sync-upstream.sh

# 仅同步 superpowers
./scripts/sync-upstream.sh --superpowers

# 仅同步 gstack
./scripts/sync-upstream.sh --gstack

# 检查更新但不执行
./scripts/sync-upstream.sh --check

# 同步前备份
./scripts/sync-upstream.sh --backup
```

### 扩展自定义技能

1. **创建自定义技能**：在 `skills/custom/` 目录下创建新技能
2. **配置覆盖**：在 `overrides/skill-overrides.json` 中配置替换或扩展
3. **应用补丁**：在 `patches/` 目录下创建补丁文件

详细说明请查看 [MAINTENANCE.md](MAINTENANCE.md)。

### 扩展 gs-hybrid-v3

**方法 1：创建扩展技能**
```
skills/custom/gs-hybrid-v3-extended/
├── SKILL.md              # 扩展后的技能定义
└── custom-phases/        # 自定义阶段
```

**方法 2：配置扩展**
```json
// config/gs-hybrid-config.json
{
  "base_skill": "gs-hybrid-v3",
  "customizations": {
    "additional_phases": [...]
  }
}
```
